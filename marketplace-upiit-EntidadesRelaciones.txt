[Posee]
Atributos:
N/A


Entidades:
Usuario, (1:N)
Producto, (N:1)


Descripción:
Un Usuario Puede Poseer Varios Productos.
Cada Producto Pertenece A Un Solo Usuario.




[Se_publica_como]
Atributos:
N/A


Entidades:
Producto, (1:N)
Publicacion, (N:1)


Descripción:
Un Producto Puede Tener Varias Publicaciones.
Cada Publicación Corresponde A Un Solo Producto.




[Realiza]
Atributos:
N/A


Entidades:
Usuario, (1:N)
Reserva, (N:1)


Descripción:
Un Usuario Puede Realizar Varias Reservas.
Cada Reserva Es Realizada Por Un Solo Usuario.




[Recibe]
Atributos:
N/A


Entidades:
Publicacion, (1:N)
Reserva, (N:1)


Descripción:
Una Publicación Puede Recibir Varias Reservas.
Cada Reserva Corresponde A Una Sola Publicación.




[Es_utilizada_en]
Atributos:
N/A


Entidades:
Ubicacion, (1:N)
Reserva, (N:1)


Descripción:
Una Ubicación Puede Ser Utilizada En Varias Reservas.
Cada Reserva Utiliza Una Sola Ubicación.




[Establece]
Atributos:
N/A


Entidades:
Usuario, (1:N)
Horario_disponibilidad, (N:1)


Descripción:
Un Usuario Puede Establecer Varios Horarios De Disponibilidad.
Cada Horario De Disponibilidad Pertenece A Un Solo Usuario.
